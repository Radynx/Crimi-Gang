# Crimi Gang

Frontend statico per il futuro shop di `Crimi Gang`, pensato per GitHub Pages.

## Contenuto

- `index.html`: struttura della home/shop
- `styles.css`: styling responsive con palette verde e azzurro
- `script.js`: piccolo script per il footer

## Pubblicazione veloce

1. Carica questi file sul branch `main` del repository.
2. In GitHub vai su `Settings > Pages`.
3. Imposta come source `Deploy from a branch`.
4. Seleziona `main` e la root `/`.

Quando arriveranno logo, foto e prodotti reali, possiamo trasformare i placeholder in uno shop completo.
